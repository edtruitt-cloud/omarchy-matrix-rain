### Maintainer notes

Matrix Rain is an animated digital rain wallpaper for every monitor: weather
presets, 20 single and 16 multi-colour looks (one can recolour the Omarchy
theme on request), glyph sets including your own symbols, depth layers,
reactions (beat, tempo, notifications, CPU, mouse, workspace, idle, typing)
and rain events. Rendering is a GPU shader; it pauses per monitor while a
window is fullscreen and stops entirely when paused. Typing ripples are off by
default (they add pass-through Hyprland key binds only while enabled; see
SECURITY.md). No network access, no idle/lock changes, no config edits. An
optional screensaver companion needs a separate local build. See
docs/RELEASE.md for what was tested.
